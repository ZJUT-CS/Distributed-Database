# 用户模块测试报告

## 概述
- 模块范围：`com.team.skylink.module.user`
- 测试类型：单元测试、集成测试、功能测试、边界与异常测试
- 测试框架：JUnit 5、Spring Test、Mockito
- 覆盖目标：公共方法覆盖率≥90%

## 测试用例清单
- AuthServiceImplTests
  - 登录成功/手机号不存在/密码不匹配/账号禁用
  - 手机注册成功/已注册冲突/性别格式异常
  - 查询用户、更新资料（邮箱/头像/性别/实名与证件规则）、绑定邮箱与手机（验证码与格式、唯一性）、修改密码（旧密码校验与长度）
- InMemorySessionStoreTests
  - 会话创建与解析（用户/管理员）、空令牌解析
- UserAuthControllerTests
  - 会话创建成功（调用服务）、请求体验证失败（400）
- UserControllerTests
  - 未登录访问个人信息/更新资料/修改密码/绑定联系方式返回业务码 401
  - 携带令牌解析登录态并返回个人信息

## 集成与交互
- 控制器通过 MockMvc 验证与服务层交互契约
- 服务层通过 Mockito 验证与数据访问层、密码编码器、会话存储交互逻辑

## 边界与异常
- 输入为空/格式不合法：邮箱、手机号、证件号、头像 URL
- 业务冲突：手机号唯一性、重复实名认证
- 安全约束：密码长度、旧密码校验、账号状态

## 执行与报告
- 执行命令：`mvn clean test jacoco:report`
- 报告位置：`target/site/jacoco/index.html`、`target/site/jacoco/jacoco.xml`
- 结果：全部测试用例通过，覆盖率达到目标要求
